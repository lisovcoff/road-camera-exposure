# Решение проблем

[English](troubleshooting.md) · [Установка](installation.ru.md)

| Симптом | Что проверить |
| --- | --- |
| Нет Picamera2/libcamera | Пакеты ОС, venv с `--system-site-packages`, активацию окружения |
| Нет камеры / занята | Шлейф при выключенном питании, другие программы, `roadcam inspect` |
| Нет нужных контролов | Требуются IMX708 и независимые выдержка/усиление; проверьте SDK |
| Нет коэффициентов цвета | Выполните `roadcam reference`, используйте созданный `config.json` |
| Каталог существует | Выберите новый, прежние опыты не перезаписываются |
| Нет трансляции на другом устройстве | Локальный IPv4 Pi, одна сеть и firewall; loopback доступен только на Pi |
| Кадр перевёрнут | `rotate_preview`; координаты конфигурации неповёрнутые |
| UNKNOWN / 4 мс | ROI, прямоугольник мишени, текстуру, положение и свет |
| Темно / шумно | Короткая выдержка собирает меньше света; добавьте свет или уменьшите движение, сравнивайте шум и смаз вместе |
| Сессия завершилась | Время, свободное место, лимиты и `summary.json`; резерв минимум 1 ГБ |
| Низкий fps просмотра | Частоты сенсора и JPEG/сети/браузера различаются |

Журналы могут содержать комнатные снимки и сведения системы. Проверяйте их перед публикацией. Сохраняйте оригиналы, новые результаты пишите в новые каталоги.
