# Установка на Raspberry Pi

[English](installation.md) · [Главная](../README.ru.md)

Нужны Raspberry Pi OS 64-bit и Pi 5 + Camera Module 3 Standard/IMX708. Опыт выполнен на Debian 13, Python 3.13.5, Picamera2 0.3.37 и libcamera 0.7.2. Это зафиксированные версии, а не гарантия для всех выпусков ОС. Реорганизованный пакет проверен офлайн и с имитацией камеры; первый реальный запуск нужно проверить.

Подключайте шлейф при выключенном питании. Все команды ниже выполняются **в терминале Raspberry Pi**, не в Windows PowerShell.

## Установка

Picamera2 и libcamera должны поставляться вместе с ОС. Не заменяйте их несогласованными сборками из pip. Для минимального образа:

```sh
sudo apt update
sudo apt install --no-install-recommends python3-picamera2
sudo apt install git python3-venv python3-pip python3-setuptools
git clone https://github.com/lisovcoff/road-camera-exposure.git
cd road-camera-exposure
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
python -m pip install --no-build-isolation --no-deps -e .
python -c "import picamera2, libcamera, numpy, simplejpeg; print('Camera dependencies available')"
roadcam inspect
```

Ожидаются сообщение о зависимостях и список с `imx708`. Пустой список — камера недоступна. Другой сенсор требует адаптера. Если отсутствуют NumPy или simplejpeg, установите пакеты ОС `python3-numpy` / `python3-simplejpeg` и повторите проверку в активном окружении.

## Опорный кадр и сцена

Закройте другие программы камеры. Положите контрастную карточку на пол, зафиксируйте камеру, свет и карточку:

```sh
mkdir -p runs
roadcam reference --config configs/module3.example.json --output runs/reference --run-camera
```

Ожидаются `reference.jpg`, `metadata.json`, `camera.json`, `config.json` и сводка в **новом** каталоге. Измеряются штатные AE/AWB, коэффициенты цвета переносятся в конфигурацию. Фокус, расстояния и дорожная геометрия не калибруются.

Откройте полноразмерный `reference.jpg`, измените `runs/reference/config.json`:

| Параметр | Значение |
| --- | --- |
| `roi` | `[x0,y0,x1,y1]` в исходном **неповёрнутом 1920×1080** кадре; чётные координаты, ширина 64–640, высота 64–360 |
| `tracking_rectangle` | Прямоугольник текстуры относительно кропа; минимум 32×32, отступ от границ минимум 8 пикселей |
| `lens` | Ручной фокус в диоптриях, допустимо 0–2; обратное расстояние в метрах — только отправная точка; проверяйте детали |
| `colour_gains` | Два измеренных коэффициента AWB; чужие значения не копировать |
| `rotate_preview` | Поворот отображения на 180°; координаты и трекер остаются неповёрнутыми |
| `bind`, `port` | По умолчанию `127.0.0.1`, порт 8000 |
| `duration_s` | Ограничение сессии, по умолчанию 3600 секунд |
| лимиты места | `session_bytes`, `validation_bytes`, `reserve_bytes`; резерв минимум 1 ГБ |

После изменения фокуса переснимите эталон, если изменился вид мишени. Каждый запуск создаёт новый эталон трекера: сначала карточка должна лежать в заданном прямоугольнике. Пример координат условный, высота и расстояния автоматически не определяются.

## Запуск и трансляция

```sh
roadcam run --config runs/reference/config.json
roadcam run --config runs/reference/config.json --output runs/demo-001 --run-camera --allow-lab
```

Первая команда: `dry_run: true`, `camera_started: false`. Вторая: цветной MJPEG-кроп на <http://127.0.0.1:8000/>. Флаг `--allow-lab` обозначает опыт на мишени без дорожной калибровки. Остановка — Ctrl+C; проверьте ошибки и завершение в `summary.json`. Для каждого запуска нужен новый каталог результатов.

Для телефона/компьютера в той же доверенной сети:

```sh
hostname -I
```

Выберите локальный IPv4 Pi и подставьте вместо примера:

```sh
roadcam run --config runs/reference/config.json --output runs/demo-002 --run-camera --allow-lab --bind 192.168.1.50
```

На другом устройстве откройте `http://192.168.1.50:8000/`. Авторизации/TLS нет, порт в Интернет не пробрасывать. Wi-Fi настраивается средствами Raspberry Pi OS, пароли в проекте не хранятся.

Страница записывает одну ограниченную проверку: подготовка, 3 с неподвижно, 6 с движение карточки, 6 с неподвижно. Камеру/свет не менять. Локально сохраняются цветные JPEG, яркостные массивы и метаданные; Git их исключает. Просмотр обновляет кроп примерно 10 раз/с, это не гарантия полноразмерного потока 30 fps.

Проверяйте реальные выдержку/усиление, подтверждение команд, время кадров, фокус и конфигурацию. При движении выдержка сокращается, после остановки возвращается штатная. Сравнивайте режимы при одинаковых скоростях. В темноте сокращение выдержки обменивает смаз на шум.
