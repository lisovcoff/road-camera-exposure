# Измерение оперативной памяти на Raspberry Pi

26 октября 2026. Измерен действующий цветной adaptive live v02 без его
остановки. Чтение /proc, без sudo и системных изменений. Камера дополнительно
не открывалась. Единицы ниже МиБ = 1024² байт; /proc kB фактически KiB.

Десять наблюдений с интервалом около 1 с:

| Показатель процесса live | Результат |
|---|---:|
| RSS | 94.97 МиБ, неизменен на этой выборке |
| VmHWM, максимум RSS с запуска | 96.92 МиБ |
| PSS, shared pages распределены пропорционально | 86.43–86.46 МиБ |
| RssAnon | 43.84 МиБ |
| VmSwap | 0 |

В процессе находятся Python/NumPy, Picamera2/libcamera, motion tracker,
policy, веб-сервер и цветной preview. RSS не является памятью только
формулы управления. Некоторые kernel/DMA camera buffers могут учитываться
отдельно; это не полный RAM footprint всей камеры/ОС. Системе доступно
7702–7710 МиБ (около 7.52 ГиБ), MemTotal 8255824 KiB, swap не использован.

Дополнительно отдельный процесс на той же Pi проиграл 101 сохранённый кадр
через TargetTracker+ShutterPolicy, без camera factory, HTTP и JPEG encoding:

| Изолированный replay | RSS |
|---|---:|
| Python + NumPy до импорта алгоритма | 23.05 МиБ |
| После импорта алгоритма | 24.05 МиБ |
| Наибольший sampled RSS во время replay | 28.50 МиБ |
| Добавка относительно baseline | около 5.45 МиБ |

Добавка включает tracker/policy, входные данные/JSON и временные NumPy buffers;
не является точным выделением памяти математического ядра в живом процессе.
Replay занял 1.64 с, использовались реальные сохранённые crops. VM counters
Linux приблизительны и могут обновляться по-разному: VmHWM в конце 28.14 МиБ,
ru_maxrss 27.78 МиБ; поэтому изолированный результат округляется до 28–29 МиБ,
а добавочный расход до 5–6 МиБ, без ложной точности.

Это короткое наблюдение, не длительный leak/stress test. Рост при включении
проверочной записи, другом разрешении/числе зрителей отдельно не измерен.
Материалы находятся в игнорируемом runs/colour_preview_20261026_001:
ram_measurement_001.json и ram_algorithm_replay_001.json.
Код не менялся, новые тесты не запускались; последняя проверка кода —
117 тестов предыдущего этапа. Откат не требуется, live продолжает работать.
