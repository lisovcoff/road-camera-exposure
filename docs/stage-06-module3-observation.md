# Этап 6: первый запуск наблюдателя на IMX708

22 октября 2026 года. Пользователь разрешил этот и последующие опыты.
Выполнен один 15-секундный лабораторный запуск версии из коммита `f11ebbd`.
Управление выдержкой и усилением со стороны нашей политики не включалось.

## Условия и воспроизводимость

До записи проверены свободное место (2 242 658 304 байт), питание
(`throttled=0x0`) и температура (48,8 °C). Работавших процессов Python/rpicam
не обнаружено. Три исходника и один конфиг скопированы в новый каталог опыта,
без замены старых файлов. Их SHA-256 на Windows и Pi совпали:

| Файл | SHA-256 |
|---|---|
| `road_core_v02.py` | `e53344e005c50ef15c3314d176928e62b3a251975da9d80153f57f7f6614889a` |
| `road_observer_v01.py` | `11e55c9943061ba420279d55c7bc55cca1778e592267e6c907cfba31fce44f92` |
| `road_pi_observe_v01.py` | `7cfd71e9b1270b4194a66c3dc457a447dce6f7ce65d2885a4b5ec2d5d644c079` |
| `pi_observer_lab_v01.json` | `a76d804661a5736f15cf92f981608e5f341d1204a2eb4e784eaed9ca625c167b` |

Команда **на Raspberry Pi**, из нового каталога с `code/` и `configs/`:

```bash
timeout --signal=INT --kill-after=5s 45s python3 -B code/road_pi_observe_v01.py --run-camera --allow-uncalibrated-lab --output run_001
```

`run_001` до запуска не существовал. Внешнее ограничение 45 с учитывает
запуск/закрытие камеры сверх 15-секундной петли. Команда завершилась с кодом 0,
ограничитель времени не сработал. Ожидаемые файлы действительно получены:
`setup.json`, `observations.jsonl`, `summary.json` и три JPEG.

Система: Picamera2 0.3.37, libcamera 0.7.2+rpt20260817, Python 3.13.5,
NumPy 2.2.4. Журнал libcamera подтвердил штатный tuning `imx708.json`,
сенсор 2304×1296 10 bit. Основной поток — 1920×1080 YUV420, stride 1920;
малый — 320×180 YUV420, stride **384**, transform identity. Подкладка строк
малого потока корректно исключена из измерений. В журнале запуска были
предупреждения Unsupported V4L2 pixel format Nc30/Nc12; после них настройка
и захват завершились успешно. Причина предупреждений отдельно не исследована.

Во всех строках есть валидная статистика и `UNCALIBRATED_ROI`, `ADJUSTING`,

`command_dispatched=false`, исполняемые/ожидающие команды пусты. Рекомендация
4000 мкс / gain 16 оставалась только рекомендацией. Текст `reason` содержит
унаследованное от ядра «dispatch required»; это не свидетельство отправки.

Полей `HdrChannel`, `ExposureTimeMode`, `AnalogueGainMode` в метаданных нет.
Состояние HDR независимо не подтверждено. Постоянное положение линзы и
AfState не доказывают наведение на нужную дистанцию; автофокусировка не
запрашивалась. FocusFoM 5…13 не является калиброванной мерой резкости.

Температура по записанным проверкам около 48–50 °C; флаги throttled оставались
0x0. После опыта свободно 2 241 925 120 байт. Процесс наблюдателя завершился;
stop/close не сообщили ошибку. Повторное открытие камеры после опыта и
поведение при реальном сбое драйвера ещё не проверены.

Все шесть файлов скопированы в локальный игнорируемый каталог
`runs/pi_observer_20261022_01/run_001/`. Их SHA-256 совпали с файлами на Pi.
Сырые журналы и фотографии не входят в публичный репозиторий.

## Что это означает для дорожной задачи

Просмотренные первый и последний JPEG показывают тёмную комнатную сцену,
видимый шум и низкую различимость деталей. Это не дорога и не испытание
движения. Даже штатная автоматика с выдержкой 32,68 мс и gain 16 не обеспечила
яркое изображение в лабораторных зонах. Уменьшение выдержки до 4 мс при прочих
равных уменьшит собранный свет примерно в 8,17 раза (около трёх ступеней).
По этим данным нельзя обещать одновременно малый смаз, низкий шум и нужную
яркость. Нужны измерения на реальной дорожной сцене и оценка освещения.

Критерии этого этапа выполнены: реальный захват, проверяемые метаданные и
stride, ограниченный объём записи, отсутствие команд политики и штатное
закрытие. Качество изображения на дороге, фокус, оптимальная выдержка,
кодирование и передача видео **не подтверждены** этим опытом.

Следующий небольшой опыт: измерить квантование и задержку применения
выдержки/усиления с выключенной AE на ограниченной серии кадров; сначала
подготовить новый versioned скрипт и офлайн-проверки. Отдельно измерить
кодирование в ограниченный sink без сетевого сервиса. Получатель, соединение
и протокол передачи пока не выбраны. Геометрия Module 3 и дорожные зоны
потребуют её собственных кадров; маски старого регистратора не переносятся.
