# Этап 9: промежуточные выдержки и дробное усиление

22 октября 2026 года. После отказа предыдущего опыта выполнены 25 ступеней
новой программой `road_pi_controls_v02.py`: 450 записанных наблюдений плюс
6 стартовых. Старые программа, калибровка и неудачный опыт сохранены.

Проверены выдержки 2000, 2471, 3039, 3799, 4000, 4976, 6215, 7745, 8000,
9999, 12000 мкс и дробные усиления от 2 до 16. Все последние шесть
наблюдений каждой ступени устойчивы. Подтверждён случай **2471→2431 мкс**.
Максимальная ошибка выдержки — **40 мкс**, gain — **0,216418** при запросе
15,5 (фактически около 15,28358).

Новые эмпирические допуски: **42 мкс** и **0,226418 gain**. Это envelope
проверенных точек; они не доказывают отсутствие большей ошибки между ними.
Код не расширяет допуски при работе регулятора, тайм-аут сохраняется.
Верхние критерии принятия расширенной измерительной серии заданы заранее:
80 мкс и 0,30 gain; серия им соответствует. Отправка → наблюдение первого
совпадения: 365,94…566,44 мс. Для первой ступени задержка не рассчитывалась.

Код возврата 0, ошибок и ошибок cleanup нет. Записано 425 491 байт, без фото
и видео; CPU-время 1,593 с. После опыта 2 241 015 808 байт свободно,
throttled=0x0, 49,4 °C. Предел цикла 30 с, внешний — 50 с, резерв microSD
1 ГБ, выходной бюджет 5 МБ. AE выключена, фокус фиксирован 1,0 и не
калиброван для дороги. Сенсорный режим прежний; HDR явно не менялся.

Команда **на Pi** из каталога с зависимостями:

```bash
timeout --signal=INT --kill-after=5s 50s python3 -B code/road_pi_controls_v02.py --run-camera --output run_002
```

Два новых офлайн-теста проверяют учёт ошибки 40 мкс и дробного gain,
а также отказ при превышении границ/нестабильности. Они прошли. Полный набор:
70 тестов, 66 успешных и 4 ожидаемых падения v0.1.

Команды **в Windows PowerShell**:

```powershell
python -B code/road_pi_controls_v02.py
python -B -m unittest discover -s tests -p 'test_controls_v02.py' -v
```

создана резервная копия. Результаты локально:
`runs/pi_controls_20261022_02/run_002/`; они не публикуются. На Pi добавлен
новый файл и новый каталог результата, старые не заменены; системные
пакеты и настройки прежние. Откат — использовать старые версии.
