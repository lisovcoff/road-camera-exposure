# Этап 14: первая серия фокуса и выдержек на подготовленной сцене

22 октября 2026 года. Высота камеры по сообщению пользователя 1,20 м.
Расстояния **от объектива напрямую**: метки 1,35 / 1,70 / 3,00 м,
лист с надписью 2,50 м. Для данного опыта дальняя граница — 3 м.
Физические размеры меток не сообщены, поэтому масштаб см/пиксель не определён.

После изменения наклона сделан новый контрольный захват на 2 с существующим
наблюдателем: 4 наблюдения, 1 JPEG, без ошибок. Затем новая программа
`road_pi_focus_v01.py` выполнила серии ручного фокуса и выдержек на IMX708.
Основной поток 1920×1080 YUV420, sensor 2304×1296 10 bit, identity; картинка
физически перевёрнута. HDR и tuning не менялись. JPEG и метаданные каждой
сохранённой фотографии получены из одного request.

## Метод

Фокус: позиции 0 / 0,2 / 0,35 / 0,5 / 0,65 / 0,8 / 1 / 1,3 / 1,6 / 2,
затем повторы 0,5 / 0,35 / 0,65. На каждой позиции ожидались совпадение
метаданных и не менее 0,8 с после отправки, затем три измерения и один JPEG.
AE выключена, запрошены 32680 мкс и gain 7,062068939; реальные значения
записаны. AF — Manual. Совпадение LensPosition не доказывает оптическое
качество само по себе. Значение 0 номинально означает бесконечность, но
не заменяет проверку реальной оптики:
[руководство Picamera2](https://datasheets.raspberrypi.com/camera/picamera2-manual.pdf).

Выдержки: 2000 / 4000 / 8000 / 16000 / 32680 мкс, gain тот же,
LensPosition=0,35. Последний выбран для отдельной предварительной серии
до завершения анализа фокуса; это **не** утверждённый оптимум.

Программа фиксирует запрос и фактическую экспозицию, аналоговое/цифровое
усиление, время сенсора и наблюдения, focus, crop и другие доступные поля.
Пределы: 30 МБ записи, JPEG до 3 МБ, свободный резерв 1 ГБ, общий цикл
до 65 с, отдельный request до 2 с. Отсутствие readback прекращает опыт.
Сетевых сервисов и установки пакетов нет.

## Ограничение неподвижности

Во время фокусной серии положение листа заметно менялось: по JPEG его
верхняя граница оказалась в диапазоне y≈485…554, левая x≈943…953.
Между фокусной и экспозиционной сериями композиция изменилась ещё сильнее.
Причина по изображениям не устанавливается: это не приписывается ни
пользователю, ни одному только перемещению линзы. Участие движения камеры,
breathing и динамики сцены не разделено.

Первоначальная фиксированная область [800,440,1025,545] поэтому не является
надёжным одинаковым измерением листа. Её онлайн-оценки не используются
для окончательного ранжирования. После захвата лист отслежен отдельно на JPEG:
в поисковой области [700,350,1250,750] выбран крупнейший связный по четырём
соседям компонент с min(R,G,B)>190 и B>0,95R. К его bbox добавлено 8 пикселей.
Все 13 bbox визуально/по координатам согласуются с листом примерно 183–186
на 69–71 пиксель. Это диагностическое выделение белой бумаги, а не детектор
окурков или универсальный алгоритм дорожного ROI.

## Предварительный результат фокуса

Градиентная энергия — среднее квадратов горизонтальных и вертикальных
разностей JPEG L с суммированием; Laplacian variance — дисперсия дискретного
лапласиана. Числа относительные, зависят от ISP, шума, JPEG и выбранной области.
Это не MTF, не физическое разрешение и не оценка качества распознавания.

| LensPosition | Градиентная энергия листа с полем | Laplacian variance |
|---|---|---|
| 0,0 | 118,35 | 167,44 |
| 0,2 | 93,08 | 107,15 |
| 0,35 | 65,02; повтор 72,55 | 54,24; повтор 64,96 |
| 0,5 | 37,88; повтор 30,95 | 16,78; повтор 13,14 |
| 0,65 | 40,52; повтор 42,00 | 19,19; повтор 21,01 |
| 1,0 | 42,76 | 20,88 |
| 2,0 | 24,82 | 7,91 |

Положение 0,0 — лучший **кандидат среди снятых** по границам листа;
1,0 не выглядит обоснованным выбором для этой сцены. Однако 0,0 снято один
раз, это граница сетки, а движение не исключено. Оптимум и глубина резкости
для всех трёх меток **не подтверждены**. Внутри листа надпись малоконтрастна;
нужен повтор с толстыми тёмными линиями и неподвижной установкой.
По видимости белых меток нельзя заключать о различимости окурков 1–3 см.

## Результат выдержек

Фактический gain во второй серии 7,0136986; DigitalGain около 1,007…1,012.
Экспозиционная серия в основном сохраняет свою композицию, отличную от
фокусной. Для ориентировочной яркости выбран один и тот же внутренний
участок листа [1490,370,1640,410] на сохранённых JPEG:

| Запрос, мкс | Фактически, мкс | Средняя яркость участка JPEG L |
|---|---|---|
| 2000 | 1977 | 62,79 |
| 4000 | 3981 | 95,43 |
| 8000 | 7989 | 138,36 |
| 16000 | 15979 | 179,98 |
| 32680 | 32653 | 228,36 |

JPEG L — не линейная величина света, не сенсорная Y и не SNR. Визуально
2–4 мс заметно темнее длинной выдержки. Усиление 16 в этой серии не проверено;
нельзя утверждать, что комнатный свет недостаточен при всех допустимых gain.
Механический смаз движущейся камеры не измерялся, поэтому выбор дорожной
выдержки по этим статичным кадрам преждевременен.
