# Этап 8: остановка первого замкнутого опыта

22 октября 2026 года. Добавлен `road_pi_loop_v01.py`: 16-секундный
лабораторный регулятор выдержки при фиксированном gain 16, со скоростью
SIMULATED 8/13/8, одним запросом в полёте и тайм-аутом 1 с.
Калибровка проверяется по модели, полной конфигурации и версиям.
Это проверка пути управления, не дорожное испытание.

Реальный запуск **не прошёл критерий подтверждения**: после 26 наблюдений
он завершился с кодом 1 и CONTROL_TIMEOUT. Отправлена одна команда,
подтверждённых нет, cleanup без ошибок, throttled=0x0.

Причина установлена по журналу: запрос **2471 мкс / 16** привёл к устойчивым
**2431 мкс / 16**, расхождение **40 мкс**. Допуск 25 мкс из этапа 7 был получен
по редкой сетке и оказался недостаточен для промежуточного запроса. Увеличение
одного тайм-аута это не исправило бы. Программа правильно прекратила отправку,
но факт отказа означает, что адаптер пока не готов к произвольным командам.

Добавленные три офлайн-теста прошли: задержанные ACK без двух команд в полёте,
остановка без повторных попыток при потерянном управлении и отказ от чужой
калибровки. Простая модель имитатора использовала ошибку 19 мкс и не
предсказала обнаруженное аппаратное квантование; её предел явно учтён.
Полный набор: 68 тестов, 64 успешных и 4 ожидаемых падения старого кода.

Команда **на Pi**, из нового каталога с зависимостями:


Для локальной проверки **в Windows PowerShell**:

```powershell
python -B code/road_pi_loop_v01.py
python -B -m unittest discover -s tests -p 'test_loop_v01.py' -v
```

Журнал сохранён отдельно: `runs/pi_loop_20261022_01/run_001/`; он и опыт
на Pi не перезаписываются. Перед изменениями создана резервная копия, прежние
исходники сохранены. На Pi не менялись пакеты, tuning и постоянные сервисы.
Откат — использовать прежние версии; процесс закрыт.
