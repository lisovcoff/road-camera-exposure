# Primary references / Первичные источники

- [Raspberry Pi camera software](https://www.raspberrypi.com/documentation/computers/camera_software.html): supported stack and installation / стек и установка.
- [Picamera2](https://github.com/raspberrypi/picamera2) and [manual](https://datasheets.raspberrypi.com/camera/picamera2-manual.pdf): OS packages, environments, configuration, controls and metadata / пакеты, окружения, контролы и метаданные.
- [Raspberry Pi libcamera AE](https://github.com/raspberrypi/libcamera/blob/main/Documentation/design/ae.rst): independent exposure/gain modes / независимые выдержка и усиление.
- [V4L2 camera controls](https://docs.kernel.org/userspace-api/media/v4l/ext-ctrls-camera.html): units and auto modes / единицы и авторежимы.
- [EMVA 1288 Linear 4.0](https://www.emva.org/wp-content/uploads/EMVA1288Linear_4.0Release.pdf): sensor noise and SNR measurement / измерение шума и SNR.
- [Sayed & Brostow, CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/papers/Sayed_Improved_Handling_of_Motion_Blur_in_Online_Object_Detection_CVPR_2021_paper.pdf): motion blur and object detection / смаз и детекция.

These references motivate the approach; they do not validate this implementation. / Источники обосновывают подход, но не проверяют данную реализацию. [Project evidence / Измерения проекта](results.md).
