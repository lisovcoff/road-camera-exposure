# Этап 13: проверка подготовленной сцены перед подбором фокуса

22 октября 2026 года. Пользователь подготовил сцену: высота камеры 1,20 м,
три метки из малярного скотча на расстояниях 1,35 / 1,70 / 3,00 м и лист
с надписью на 2,50 м. Расстояния измерены **напрямую от объектива**,
не по полу. Для текущего опыта дальняя мишень — 3 м; это не подтверждение
геометрии будущей установки на машине.

Перед запуском на Pi было 2 237 059 072 байт свободно, throttled=0x0,
температура 49,9 °C, процессов предыдущих опытов не обнаружено.
Проведён только контрольный запуск существующего наблюдателя:

```bash
timeout --signal=INT --kill-after=5s 45s python3 -B code/road_pi_observe_v01.py --run-camera --allow-uncalibrated-lab --output focus_scene_baseline_001
```

Команда выполнялась **на Raspberry Pi** из каталога наблюдателя. Получены
30 наблюдений и 3 JPEG; код 0, ошибки и cleanup отсутствуют, команды
экспозиции от политики не отправлялись. Камера закрыта. После опыта
throttled=0x0, 48,8 °C. Настройки ISP, HDR и пакеты не менялись.

Контрольный JPEG просмотрен: изображение перевёрнуто, основную часть занимает
комната, пол виден узкой полосой. Лист с надписью и все три метки одновременно
не идентифицируются. Надёжно назначить им отдельные ROI и провести оценку
резкости по заявленным дистанциям невозможно. Само наличие предметов в
комнате не считается проверкой их попадания в полезный кадр.

**Подбор фокуса и сравнение выдержек на мишенях не проводились.** Пользователю
сообщено, что захват завершён, камеру можно двигать и нужно наклонить вниз,
чтобы одновременно были видны ближняя и дальняя метки и лист. После изменения
наклона сначала требуется новый контрольный кадр. Цифровой разворот картинки
не исправляет физическое направление обзора.

Сырые данные и домашние фотографии сохранены только локально:
`runs/focus_scene_20261022_01/focus_scene_baseline_001/` и в новом каталоге Pi.
В репозиторий они не включены. Исполняемые исходники не изменены; добавлен
только этот отчёт и ссылка README. Для документации новые тесты не нужны;
результаты прежнего набора не выдаются за тесты нового аппаратного опыта.
Перед правками сохранена локальная резервная копия. Для отката никакое
восстановление камеры не требуется: процесс уже завершён, старые данные
и программы сохранены.
