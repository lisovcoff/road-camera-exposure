ни приёмник, ни инференс не измерены. CPU-время не является процентом
загрузки всей платы. Короткий тёмный опыт не заменяет длительную проверку
на движущейся текстурированной дороге.

## Воспроизведение

**На Raspberry Pi**, из каталога с зависимостями; output должен быть новым:

```bash
timeout --signal=INT --kill-after=5s 50s python3 -B code/road_pi_encode_v01.py --run-camera --codec h264 --calibration ../controls_v01_20261022_01/run_002/calibration.json --output h264_loop_001
timeout --signal=INT --kill-after=5s 50s python3 -B code/road_pi_encode_v01.py --run-camera --codec mjpeg --calibration ../controls_v01_20261022_01/run_002/calibration.json --output mjpeg_loop_001
```

Новый офлайн-тест одновременно имитирует задержанные команды и выход
пакетов, проверяя ACK и освобождение ресурсов. Он прошёл. Полный набор:
78 проверок, 74 успешных и 4 ожидаемых падения исторической v0.1.

**В Windows PowerShell**:

```powershell
python -B -m unittest discover -s tests -p 'test_encoded_loop_v01.py' -v
python -B -m unittest discover -s tests -p 'test_*.py'
```

Локальные данные: `runs/pi_encoded_loop_20261022_01/`, в Git не входят.
Финальная сверка SHA-256 подтвердила совпадение всех 40 выходных файлов
девяти аппаратных опытов на Windows и Pi, включая сохранённый отказ этапа 8.
Работающих процессов опытов не обнаружено; при заключительной проверке
свободно 2 237 132 800 байт, throttled=0x0, 48,8 °C.
В чистом экспорте только файлов Git повторно прошли все 78 офлайн-проверок
и dry-run наблюдателя, расширенной калибровки, loop v02 и кодировщика.
Локальные фотографии, журналы и резервные копии для этих проверок не нужны.

Исполняемые исходники на этом этапе не менялись. Добавлены интеграционный
тест, отчёт и руководство воспроизведения, обновлён README. Перед правками
создана резервная копия. Предыдущие результаты и системная конфигурация
сохранены. Откат — прежние версии; процессы уже завершены.

## Следующий практический шаг

Дальнейшая верификация качества требует физической подготовки сцены и
размеров установки; сетевой опыт требует выбранного приёмника и соединения.
Что именно подготовить, указано в [руководстве](hardware-workflow.md).
До этих данных система остаётся лабораторным прототипом. Фокус на дороге,
резкость сантиметровых объектов, движение, реакция на свет и охват двух полос
не считаются подтверждёнными.
