# Цветной просмотр при анализе яркостного канала

26 октября 2026. Предыдущий измерительный preview и проверочный MP4 были
монохромными, поскольку сохранялся только post-ISP Y. Камера и основной
YUV420 pipeline уже содержали цвет. Цветовая информация старых Y-файлов
утрачена; искусственное раскрашивание не является восстановлением источника.

Новый `road_pi_adaptive_live_v02.py` использует прежнюю политику/tracker/gate
без изменения. `road_colour_preview_v01.py` извлекает соответствующие
Y/U/V planes crop из того же main request, учитывает stride и субдискретизацию,
одинаково поворачивает три planes и передаёт их штатной установленной
simplejpeg.encode_jpeg_yuv_planes. Анализ получает прежний неизменённый Y.
Таким образом цветной вывод не требует анализа трёх RGB каналов.

Корректный YUV420 путь сверен с фактическим installed Picamera2
CompletedRequest.save. make_image не использовался: на установленной
реализации он не обеспечивает нужный прямой YUV420 путь. Новых пакетов нет.
Sensor mode, ISP, AWB reference, focus, частота/crop и policy сохранены.
Для новых проверочных запусков дополнительно подготовлено сохранение
реальных цветных JPEG из того же массива с colour_file в metadata.
Старые Y массивы по-прежнему сохраняются для измерений. Новый полный
15-секундный проверочный цветной опыт в этом этапе не запускался.

Два теста проверяют U/V separation, stride/padding, crop, согласованный
поворот, неизменность массива/Y и отказ по нечётным или внешним координатам.
Полный набор выполнен: 117 тестов, 113 успешных, четыре ожидаемых падения.
Проверено на железе: HTTP snapshot успешно декодирован Pillow как RGB
580×320; 99.4% пикселей имеют межканальную разницу >5, источник реально
цветной. Изображение просмотрено: цветные пол/рулетка/кожа, фальшивых
хроматических каналов не создавалось. Это не колориметрическая калибровка.

Прежний сервис остановлен SIGTERM без capture/cleanup ошибок, его summary
и данные сохранены. Запущен новый четырёхчасовой сервис с прежней локальной
ссылкой, новым output adaptive_colour_001; adaptive controls применяются.
До запуска свободно 1916985344 байт, резерв не менее 1 ГБ остаётся обязательным.
Во время проверки питание throttled=0x0. Для замены потока был короткий
перезапуск камеры; новые motion/reference не дают автоматического права
переносить прежний измеренный выигрыш на изменившиеся условия.

Фото и metadata проверки находятся в игнорируемом
runs/colour_preview_20261026_001, предыдущие записи не заменены.
В GitHub только новые исходники/тесты/отчёт. Перед правками создана
timestamped копия. Откат: остановить новый процесс и запустить прежний
v01; он сохранён отдельно. Настройки ОС/прошивка/tuning не менялись.
