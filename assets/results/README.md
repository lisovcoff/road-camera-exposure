# Public media / Открытые материалы

[Gallery / Галерея](index.html) · [Method EN](../../docs/results.md) · [Методика RU](../../docs/results.ru.md)

- `target-motion.mp4`: five-second four-mode target comparison, actual luminance. Separate recordings aligned by onset, not simultaneous speed-matched frames. / Пять секунд реальной яркости мишени; отдельные записи совмещены по началу движения.
- `demo-poster.png`: illustrative video frame / иллюстративный кадр.
- `line-width.png`, `.svg`: median FWHM and frame quartiles / медиана ширины и квартили кадров.
- `cpu-cost.png`, `.svg`: isolated algorithm CPU / нагрузка отдельно алгоритма.
- `measurements.json`: aggregates and limitations / агрегаты и ограничения.
- `video-provenance.json`: crop/alignment rules and source metadata hashes / правила обрезки, совмещения и хеши метаданных.
- `SHA256SUMS`: media/data checksums / контрольные суммы.

Full indoor captures are not distributed. These files support viewing the experiment and regenerating charts, not independent raw-frame reanalysis. No brightness normalization or grayscale colourization. / Полные комнатные записи не распространяются. Материалы позволяют посмотреть опыт и перестроить графики, но не повторить анализ исходников. Нормализация яркости и раскрашивание ЧБ не применялись.
